## About me

I'm a full-stack developer interested in designing scalable applications that solve operational problems — from logistics and fleet workflows to distribution, inventory, accounting and field sales.

- **Frontend:** Angular, Next.js, React, TypeScript
- **Backend:** Node.js, Express, NestJS, Fastify
- **Data:** MongoDB, PostgreSQL, Redis
- **Mobile & desktop:** Flutter, Electron, Tauri
- **Infrastructure:** Docker, AWS, Linux, Nginx, PM2
- **Interests:** Real-time systems, multi-tenant SaaS, automation and developer tooling
